# MDEP - Modular Distributed Embedded Platform



## Overview



MDEP is a modular embedded electronics platform built around a central motherboard and interchangeable peripheral modules.



## Hardware Modules



- Mainboard (prasanna) - central platform

- Audio Hub - audio-related module

- Motor Driver Hub - motor-control interface

- Sensor Hub - sensor interface



## Tools



- KiCad - schematic capture and PCB design

- Git - local version control

- GitHub - planned remote repository
